【今回の変更】
・前日のコピーの横に「？」を追加。実画面を使った簡易取説をアプリ内で表示（オフライン対応）。
・承認済みの青／青緑アイコンを採用。通常の192px・512pxとAndroidマスク対応512pxを同梱。

【GitHub更新】
ZIPを展開し、moriken-nextday-rosterのリポジトリ直下へ同名ファイルを上書きしてください。
index.html / manifest.webmanifest / service-worker.js / README.txt / icons/
既存の保存データは削除しないでください。新しいService Workerは旧版のアプリアイコンのキャッシュだけを対象に削除します。
ホーム画面アイコンは端末OSの管理であり、アプリ更新後すぐには切り替わらない場合があります。既存アプリやサイトデータを削除しないでください。

【操作】
「？」で取説。「JPEG保存」から画像確認・保存・LINE共有。表画面の「LINE共有」から直接画像共有も可能です。
通常の更新には再インストール不要。端末変更前は設定からバックアップを出力してください。
