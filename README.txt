翌日配置表 v0.1.0

GitHub Pages 公開用ファイルです。
ZIPを展開し、以下のファイル・フォルダをリポジトリ直下へアップロードしてください。

- index.html
- manifest.webmanifest
- service-worker.js
- icons/

主な機能
- 自由セル＋現場ブロック方式
- 人員・車両を「選択→現場選択」またはドラッグで移動
- 現場名を任意セルへ配置・移動
- 現場メモ／当日メモ（対応ブラウザでは音声入力）
- 休み欄
- 前日のコピー
- 元に戻す
- 端末内自動保存
- PDF・印刷
- バックアップ書き出し／読み込み

推奨ブラウザ：Microsoft Edge / Google Chrome

注意
- データはブラウザ端末内(localStorage)に保存されます。端末・ブラウザを変える場合はバックアップを使用してください。
- PDF出力時の現場名・休み欄の黄色背景は、印刷用CSSで保持するよう調整しています。
