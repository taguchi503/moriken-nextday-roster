翌日配置表 v0.5.1

GitHub Pages公開先（変更なし）
https://taguchi503.github.io/moriken-nextday-roster/

【更新】
ZIPを展開し、既存リポジトリの同じ場所に全ファイルを上書きしてください。
アプリの削除、再インストール、ブラウザのサイトデータ消去は不要です。
古い配置表を残したい場合は更新前にバックアップを出力してください。
更新後は過去の作成済み直近3日分（当日・未来分を除く）を保持し、それより古い配置表を整理します。
既存データが整理対象になる場合は初回に確認します。

【v0.5.1】
・カメラは高解像度を優先し、縮小した画面ではなく元映像の中央領域・全体を交互に認識します。
・明るさむら対策、拡大、左右反転、従来の認識処理を組み合わせます。ブラウザ標準のQR認識も維持します。
・緑の読み取り枠、認識中・解像度・試行回数を表示。全枚を読み込んだら従来どおり確認して反映します。
・QRを低密度化（分割単位820→480文字）。枚数は増える場合があります。v0.5.0で出力した1日分QRも受信できます。
・読み取れない場合はQR画像を保存し、受信側の「画像から読む」を利用してください。
・既存データ形式、保存ルール、配置・JPEG・LINE共有、URL、アイコンは変更しません。

【v0.5.0】
・QR転送は表示中の配置日1日分のみ。登録一覧・他日付は転送しません。
・該当日だけ取り込み、同じ日付は確認して上書き。過去3日分の保存ルールは維持し、整理対象がある場合は確認画面に表示します。
・複数枚の自動分割、画像・カメラ読取、全枚読込確認は維持。旧版の複数日QRは受信できません（送信側も更新してください）。
・ドラッグ先が埋まっている場合、同じ列の連続する文字を次の空きマスまで1行ずつ押し下げて挿入します。必要な場合は行を追加。移動元は空欄、他の列は変更しません。
・保存キー・文字書式・JPEG・LINE共有・登録情報・バックアップ形式・公開URL・アイコンは従来どおり。

【v0.4.0】
・現場名と人員・重機の紐付けを廃止。各マスの文字を独立してドラッグ移動・入替。
・従来の未配置項目は空きマスに移行。登録した名称は設定から再利用。
・タップで文字編集、色・サイズ変更、削除。標準16px・太字、小13.6px、大20px。
・現場名の黄色背景、現場メモと確認状態を維持。文字色の初期値は通常文字が黒、現場名が赤。
・JPEG出力とLINE共有に色・サイズを反映。
・保存期間は過去3作成日＋当日・未来分。過去の空白閲覧データは作成日に数えない。
・QRコードで保存中の配置表、登録名称等を圧縮転送。必要に応じ複数枚に分割。
・カメラ読取とQR画像読取、重複除外、全枚読取完了後の確認、同日データ上書き・他日保持。
・既存の保存キー、公開URL、アイコン、バックアップ読込形式を維持。
・画像付き取扱説明書を更新。ポータルには連携しない。

【注意】
QRはインストール不要ですが、カメラ利用にはHTTPSと端末側の許可が必要です。
端末カメラで読めない場合はQR画像を保存し、受信端末の画像読込を利用してください。
QRは会社の配置情報を含みます。第三者への送信に注意してください。
