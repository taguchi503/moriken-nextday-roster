翌日配置表 v0.1.1

GitHub Pages 更新用です。ZIPを展開し、リポジトリ直下へ同名ファイルを上書きしてください。既存データ・URL・ポータルとの独立性は維持します。

【今回の変更】
・配置表の縮小／全体（横幅に合わせる）／拡大／等倍表示
・PDF・印刷ボタンをJPEG保存とLINE共有に変更
・A4横比率のJPEG。黄色い現場名・休み欄を保持し、画面拡大率と無関係に全配置表、休み、当日メモを出力
・通常は約50KBを目標に圧縮。配置が多い場合は読みやすさを優先するため容量が増える場合があります。LINE側の再圧縮後の容量は端末・アプリ設定によります。
・LINE共有：スマホの共有画面→LINE→トークルームを選択して送信。非対応端末ではJPEG保存後にLINEから添付。
・端末内保存キーとデータ形式・バックアップ形式を維持。キャッシュ全削除、localStorage削除は行いません。

上書き対象：index.html、manifest.webmanifest、service-worker.js、README.txt、icons/（既存と同一）
既存の前日コピー、元に戻す、現場・人員編集、休み、メモ、バックアップ等はそのままです。
通常の更新にサイトデータ削除や再インストールは不要です。端末変更前はバックアップしてください。
